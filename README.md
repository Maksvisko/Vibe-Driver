# 🕹️ VIBE DRIVER

3D-гонки в стиле PS1, где **главный герой — музыка**. Тёмная трасса неонового ночного города, простое удобное управление, живая физика с дрифтом и колесо радио, куда ты сам подбираешь треки.

## Быстрый старт

```bash
npm install
npm run scan-music   # соберёт playlist.json из public/music/
npm run dev          # http://localhost:5173
```

## Свои треки

**Два способа добавить музыку:**

1. **Файлы в проект**
   - Положи аудио (`.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`) в `public/music/`
   - Именуй файлы как `Artist - Title.mp3` — тогда в меню будет видно артиста
   - Запусти `npm run scan-music`
   - Обнови страницу и нажми **TAB** — колесо радио
2. **Перетаскивание в окно** — просто сбрось аудио-файл прямо на игру: появится оверлей *DROP YOUR MUSIC*, трек мгновенно добавится в колесо и включится.

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `S` (или ↑/↓) | Газ / тормоз-задний ход |
| `A` / `D` (или ←/→) | Руль |
| `SPACE` | Ручник (риф для дрифта) |
| `TAB` | Колесо радио |
| `C` | Вид камеры: спозад / салон (первое лицо) |
| `ENTER` (в колесе) | Играть выбранный трек |
| `Q` / `E` | Переключение треков в колесе |
| `P` | Пауза музыки |
| `[` / `]` | Предыдущий / следующий трек |
| `R` | Вернуться на трассу |
| `M` | Звук двигателя вкл/выкл |
| `ESC` | Пауза |

## Что внутри

- **PS1-рендер** (`src/render/ps1.js`) — низкое разрешение рендера (240–280px), пиксельный дитеринг Байера, квантизация цвета, виньетка (без вершинного snap — он рвал геометрию)
- **Физика авто** (`src/game/carPhysics.js`) — простая стабильная аркадная физика (стиль OutRun/Ridge Racer): `speed += accel·dt` с жёстким лимитом 180 км/ч, рулёжка только в движении, плавный drag, ручник для заносов, отбойники без вылета и fail-safe ресpawn при NaN/выходе за границы. Проверяется `npm run test:physics`
- **Трасса** (`src/game/track.js`) — процедурный ночной город: закрытый сплайн, стены, свет, небоскрёбы. Неон регулируется по басам: `emissiveIntensity` барьеров и фонарей резко взлетает на ударе бита и плавно затухает (lerp)
- **Вид от первого лица** (`C`) — `CHASE_VIEW` (спозад) ↔ `COCKPIT_VIEW` (салон): камера на уровне глаз водителя (x:-0.25, y:1.2, z:0.1), строгий взгляд на горизонт через лобовое стекло, фиксированный FOV 72 (без сужения от скорости и пульсации — они только для вида сзади), наклон в поворотах (lean), высокочастотная тряска на скорости, near-clip под капот, приглушенный HUD. Интерьер (`src/game/carModel.js`): руль, который вращается по A/D, панель приборов и неон-индикаторы, пульсирующие по басу
- **Колесо радио** (`src/ui/radioWheel.js`) — вращающееся меню треков, динамически перерисовывается при добавлении треков, с ретро-эквалайзером (спектр) в центре
- **Музыка** (`src/audio/music.js`) + **двигатель** (`src/audio/engineSound.js`) — WebAudio, анализатор (FFT 256) для HUD-эквалайзера, данных о басах и громкости
- **Реактивный мир** — Camera Shake при сильных низких частотах, пульсация FOV «дыханием» при высокой громкости, пульсация неонового света в такт басу

## Деплой на GitHub Pages

Настроен автоматический деплой: `.github/workflows/deploy.yml` собирает проект и публикует `dist/` на Pages при пуше в `main`.

1. Репозиторий → **Settings → Pages → Source: GitHub Actions**
2. Пуш в `main` → вкладка **Actions** → workflow **Deploy to GitHub Pages**
3. Сайт: `https://<user>.github.io/Vibe-Driver/` (`base: '/Vibe-Driver/'` уже в `vite.config.js`)

## Музыка без треков

Если `public/music/` пуст или `playlist.json` не найден — игра не падает: подхватывает **built-in Synthwave-плейлист** (3 атмосферных трека со стриминговых GitHub-CDN, с CORS для анализатора). Если и они недоступны — в крайнем случае стартует встроенный **Synthwave loop** (Web Audio API, Am–F–C–G, барабаны + бас + арпеджио). Как только добавишь свои треки через `npm run scan-music` или перетащишь файл в окно, они появятся в колесе радио.
