# 🕹️ VIBE DRIVER

3D-гонки в стиле PS1, где **главный герой — музыка**. Тёмная трасса неонового ночного города, простое удобное управление, живая физика с дрифтом и колесо радио, куда ты сам подбираешь треки.

## Быстрый старт

```bash
npm install
npm run scan-music   # соберёт playlist.json из public/music/
npm run dev          # http://localhost:5173
```

## Свои треки

**Два способа добавить музыку:**

1. **Файлы в проект**
   - Положи аудио (`.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`) в `public/music/`
   - Именуй файлы как `Artist - Title.mp3` — тогда в меню будет видно артиста
   - Запусти `npm run scan-music`
   - Обнови страницу и нажми **TAB** — колесо радио
2. **Перетаскивание в окно** — просто сбрось аудио-файл прямо на игру: появится оверлей *DROP YOUR MUSIC*, трек мгновенно добавится в колесо и включится.

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `S` (или ↑/↓) | Газ / тормоз-задний ход |
| `A` / `D` (или ←/→) | Руль |
| `SPACE` | Ручник (риф для дрифта) |
| `TAB` | Колесо радио |
| `C` | Вид камеры: спозад / салон (первое лицо) |
| `ENTER` (в колесе) | Играть выбранный трек |
| `Q` / `E` | Переключение треков в колесе |
| `P` | Пауза музыки |
| `[` / `]` | Предыдущий / следующий трек |
| `R` | Вернуться на трассу |
| `M` | Звук двигателя вкл/выкл |
| `ESC` | Пауза |

## Что внутри

- **Стиль и атмосфера** (NFS1 / OutRun / Miami Vice) — сочная, контрастная картинка: фон сцены глубокий индиго `#0e0920` (не чистый чёрный), густой атмосферный туман `FogExp2(0x0e0920, 0.0035)` скроет резкие границы вдалеке; `AmbientLight(#334466, 0.6)` холодно-синий + лунный `DirectionalLight(#88aaff, 0.9)` сверху-сбоку — чёткие граненые блики и тени PS1-эпохи на скосах кузова и зданий
- **PS1-рендер** (`src/render/ps1.js`) — низкое разрешение рендера (240–280px), пиксельный дитеринг Байера, квантизация цвета, виньетка (без вершинного snap — он рвал геометрию). Устойчив к ресайзу: `resize(w, h)` обновляет canvas, low-res render target (высота ~260px, ширина пропорционально aspect) и resolution-uniform пост-шейдера; чёрного экрана при F11/fullscreen нет (guard на нулевые размеры + `fullscreenchange`)
- **Машина** (`src/game/carModel.js`) — кузов **жемчужно-белый металлик** (`#e8ecf4`) с глянцем (`roughness 0.35`, `metalness 0.2`): на гранях чёткие блики и тени от фонарей и неона. Неоновые акценты: продольные бирюзовые полосы по борту и капоту + яркая горизонтальная полоса задних фар во всю ширину кормы. Диски — серебро/хром (`#cccccc`), вращение колёс читается. Салон тёмный, но приборные шкалы и кнопки — неоново-светящиеся (бирюза/оранжевый)
- **Трасса** (`src/game/track.js`) — процедурный ночной город: закрытый сплайн, стены, свет, небоскрёбы. Неон регулируется по басам: `emissiveIntensity` барьеров и фонарей резко взлетает на ударе бита и плавно затухает (lerp). Дорога — тёмный графитовый асфальт `#242734` (ни в коем случае не чёрный): яркая неоново-белая пунктирная линия по центру с золотым свечением и яркие белые сплошные полосы у отбойников — бешеное чувство скорости даже в темноте. START-баннер — аккуратный прямоугольник (ширина дороги, 1.2 м, 0.2 м) на столбах над финишем на высоте 4.5 м
- **Физика авто** (`src/game/carPhysics.js`) — простая стабильная аркадная физика (стиль OutRun/Ridge Racer): `speed += accel·dt` с жёстким лимитом 180 км/ч, рулёжка только в движении, плавный drag, ручник для заносов, отбойники без вылета и fail-safe ресpawn при NaN/выходе за границы. Проверяется `npm run test:physics`
- **Вид от первого лица** (`C`) — `CHASE_VIEW` (спозад) ↔ `COCKPIT_VIEW` (салон), одна камера, переключение только режима. В цикле рендера **не создаются объекты** (векторы задекларированы один раз и переиспользуются через `.set()/.copy()`). CHASE: камера **жестко** сзади — назад 7.5 м, вверх 3.2 м по вектору движения, `lookAt` в точку на 5 м перед машиной на высоте 1.2. COCKPIT: позиция глаза водителя — поднятый и слегка выдвинутый вперёд локальный оффсет `X -0.32, Y 1.35, Z 0.35` → мировая через `localToWorld`, мгновенное копирование; взгляд направлен на точку чуть **выше горизонта** (локально `X -0.32, Y 1.5, Z 20`), так что торпеда и капот занимают не более 25–30% внизу экрана, а верхние 70–75% — чистый вид на дорогу и небо. Интерьер (`src/game/carModel.js`) — **полная пересборка салона**: широкая панель приборов с бледно-серым материалом (`#1a1b24` — читается как отдельный объём, не сливаясь с асфальтом), неоновая тонкая фаска по верхнему краю торпеды, стойки лобового стекла, центральная консоль. **Руль строго с левой стороны** — трёхспицевый ретро-руль (вращение по Z = `steerAngle * 2.5`), на нем тёмные руки водителя держатся за обода в положении 10 и 2 часов. **Тёмная модель игрока** — матово-чёрный торс, плечи, шея и голова за рулём, читается как силуэт, не перекрывая дорогу. **Нормальный салон с ручником** — рычаг ручника между сидениями на консоли с оранжевым светящимся индикатором (пульсирует по басу). **Круглая радиомагнитола** — круглый радио-диск на консоли с светящимся круглым экраном и регулятором громкости, плюс **светящийся мини-диск (винил)** справа от него — вращается во время воспроизведения и пульсирует неоном по басу. Неоновый спидометр с ретро-подсветкой, неоновые полосы и кнопки на торпеде. **Все материалы машины — `DoubleSide`**, кузов всегда виден (лобовое стекло скрыто в салонном режиме, капот остаётся внизу). Физика с угловым демпфированием yaw-rate — по прямой «по рельсам»; кузов не кренится в повороты **Все материалы машины — `DoubleSide`**, кузов всегда виден (лобовое стекло скрыто в салонном режиме, капот остаётся внизу). Физика с угловым демпфированием yaw-rate — по прямой «по рельсам»; кузов не кренится в повороты
- **Динамические фары** (`F`) — два тепло-белых `SpotLight` (`#fff8e7`, дальность 80 м, угол раскрытия ~37°) на передней части кузова, освещают дорогу и барьеры впереди. Переключение клавишей `F` (layout-independent, `event.code === 'KeyF'`): фарые включаются/выключаются, стекла фар переключают свечение (ярко-белое ↔ тусклое), нижний центр показывает ретро-нотификацию `ФАРЫ: ВКЛ` / `ФАРЫ: ВЫКЛ`. Фары выключены по умолчанию
- **Колесо радио** (`src/ui/radioWheel.js`) — вращающееся меню треков. **Слот треков рендерится сразу при инициализации плейлиста, до первого открытия меню** — на первый нажатий `TAB` все стандартные треки уже расставлены по диску и выбираются стрелками/`A`/`D`. Радиус диска измеряется с учётом скрытого оверлея (guard на нулевую ширину stage) и корректно пересчитывается при открытии меню, даже если оно строилось до первого показа
- **Музыка** (`src/audio/music.js`) + **двигатель** (`src/audio/engineSound.js`) — WebAudio, анализатор (FFT 256) для HUD-эквалайзера, данных о басах и громкости
- **Реактивный мир** — пульсация неонового света (барьеры/фонари/здания) и приборной панели в такт басу; камера стабилизирована (нет дерганья и «дыхания» FOV)

## Деплой на GitHub Pages

Настроен автоматический деплой: `.github/workflows/deploy.yml` собирает проект и публикует `dist/` на Pages при пуше в `main`.

1. Репозиторий → **Settings → Pages → Source: GitHub Actions**
2. Пуш в `main` → вкладка **Actions** → workflow **Deploy to GitHub Pages**
3. Сайт: `https://<user>.github.io/Vibe-Driver/` (`base: '/Vibe-Driver/'` уже в `vite.config.js`)

## Музыка без треков

Если `public/music/` пуст или `playlist.json` не найден — игра не падает: подхватывает **built-in Synthwave-плейлист** (3 атмосферных трека со стриминговых GitHub-CDN, с CORS для анализатора). Если и они недоступны — в крайнем случае стартует встроенный **Synthwave loop** (Web Audio API, Am–F–C–G, барабаны + бас + арпеджио). Как только добавишь свои треки через `npm run scan-music` или перетащишь файл в окно, они появятся в колесе радио.
