# 📻 Сюда клади свою музыку

Положи аудиофайлы (`.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`) в эту папку и запусти:

```bash
npm run scan-music
```

Скрипт создаст `playlist.json`, и треки появятся в колесе радио (клавиша **TAB** в игре).

## Именование файлов

Рекомендуемый формат:

```
Artist - Title.mp3
01. Artist - Title.mp3
```

Тогда в меню радио будет видно и имя артиста, и название трека.
Любое другое имя тоже сработает — просто будет `filename` как название.

После `scan-music` обнови страницу (F5) и открой колесо радио (TAB).
